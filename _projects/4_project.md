[UncertainSCI](https://github.com/SCIInstitute/UncertainSCI) is an open-source Python toolkit for noninvasive parametric uncertainty quantification of computational simulation pipelines.

As one of the contributors, I worked on numerical foundations and software pieces connected to polynomial chaos emulators, sampling strategies, and biomedical simulation use cases.

The toolkit supports:

- Polynomial chaos based surrogate modeling.
- Parameter sampling for uncertainty quantification.
- Sensitivity and variability analysis for model outputs.
- Interfaces for computational biomedical and bioengineering simulations.
